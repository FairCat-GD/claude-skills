## 3. Findings

### High

**F1. One word on the owner's term list is in the skill, on seven lines.** The example city of
the snack-stop, coffee-house, ceramics and curiosities examples: `SKILL.md:89`, `:138`, `:189`;
`references/location-block-template.md:37`, `:55`; `references/research-playbook.md:61`, `:68`.
The hygiene stage's first full scan fails on it, so Session 1 cannot go green as written.
*Remedy:* replace those examples with another city's, approved by the owner (`SPEC.md`
decision 14). Pushed history keeps the old text.

**F2. The frontmatter has a field the specification does not allow, and lacks the licence.**
`SKILL.md:3` is `version: "1.0"`; the Agent Skills specification allows only `name`,
`description`, `license`, `compatibility`, `metadata` and `allowed-tools`, and its validator
rejects any other field. There is no `license`. The `skills` stage fails on it. *Remedy:* the
version moves to `metadata.version` and to the plugin's `plugin.json`; add `license: MIT`.

### Medium

**F3. The fonts in the PDF skeleton never load.** `references/output-formats.md:130–131`: the
`@import` of the two fonts follows `@page`, and CSS ignores an `@import` that is not at the
start of the sheet, so the PDF falls back to default fonts. *Remedy:* `@import` first; confirm
with a render.

**F4. Declining food picks leaves the food appendix and its research mandatory.**
`SKILL.md:90` asks whether to include food; yet `:136` requires at least ten restaurants
researched, `:186` and `output-formats.md:108` require Appendix A with ten to fifteen entries,
and neither is conditioned on the answer. *Remedy:* say what the skill does when the answer is
No (asked at the start of Session 3).

**F5. Links are shared with a `computer://` scheme and "the workspace folder".** `SKILL.md:259`,
`references/output-formats.md:159`, `:179`. Both exist only in the Claude desktop app's
sandbox. *Remedy:* say where to save and how to hand over the file in each target.

**F6. The PDF tool is installed with a flag for one kind of environment.**
`references/output-formats.md:24`: `pip install weasyprint --break-system-packages`. The flag
overrides a system Python's protection, WeasyPrint also needs Pango from the system, and an
agent without code execution cannot install anything. *Remedy:* a fallback order, ending with
the chat format the skill already has.

**F7. The weekday check uses a GNU-only command.** `SKILL.md:132` suggests `date -d`, which
fails on macOS's `date`. *Remedy:* a portable check, or none.

**F8. Rendered pages are checked with `pdftoppm`,** a system tool that may be absent
(`references/output-formats.md:159`; `SKILL.md:254`). *Remedy:* name a fallback, or say the
check is skipped and that it was.

**F9. The interview depends on the question tool, with no fallback.** `SKILL.md:67–92` names
`AskUserQuestion` for eleven steps. Codex, claude.ai chat and other agents may not have it.
*Remedy:* the same options asked in plain chat when the tool is absent.

**F10. The fonts come from the network.** `references/output-formats.md:32`, `:131`: Google Fonts
by `@import`. An agent with no network renders default fonts. *Remedy:* say so, and what the
fallback fonts are.

**F11. The phone-reading check cannot pass as written.** `references/output-formats.md:30`, `:63`,
`:132` set A4 with a 10pt body; `:118` asks for about 11pt effective size on a 6-inch phone at
fit-to-width, where A4 shrinks to about a third. *Remedy:* reword the check or change the page
size; the owner picks from rendered samples (Session 3).
